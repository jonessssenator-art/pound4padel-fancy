# POUND4PADEL × Fancy Components

Отдельный тестовый сайт клуба. React + Vite + Tailwind + Motion.

```
npm install
npm run dev
npm run build
```

Использованы исходные Fancy Components: TextRotate, DragElements, UnderlineToBackground (MIT, Daniel Petho). Лицензия: public/FANCY-LICENSE.txt. Локальные изменения обеспечивают адаптацию и доступность.
